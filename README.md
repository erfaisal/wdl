# Web Designing Workshop (TCS-353)

This project contains the practical experiments of the Web Designing Workshop subject.

## Experiments

1. Different Styles of Heading Text
2. Patient Check-up Process using Ordered and Unordered Lists
3. Traditional Newspaper using Table Tags
4. Displaying Images with Contents
5. Displaying Various Menus using Anchor Tags
6. Image Mapping using Map and Area Tags
7. Frames with Details of Different Cities
8. Restaurant Food Order Form using Checkboxes
9. Automatic Page Reload after 5 Seconds
10. Setting Background Colour, Font and Paragraph using CSS

## Project Structure

- `index.html` - Main homepage
- `exp1.html` to `exp10.html` - Experiments 1 to 10
- Supporting HTML files - Used for image mapping and frames
- `sports.svg` - Image used in Experiments 4 and 6

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Select an experiment from the homepage.
